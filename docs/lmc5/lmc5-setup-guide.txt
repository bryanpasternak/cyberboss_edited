LMC-5 pgvector 后端部署教程
============================
最后更新：2026-07-14

本教程覆盖从零开始部署 LMC-5 的完整流程。
LMC-5 是一套 AI 长期记忆系统，支持向量检索、记忆代谢、情感评分、叙事时间线等功能。

============================
1. 前置依赖
============================

服务器要求：
- Linux VPS（推荐 Ubuntu 22.04+）
- Python 3.10+
- PostgreSQL 15+（需要 pgvector 扩展）

安装系统依赖：
  sudo apt update
  sudo apt install -y python3 python3-pip python3-venv postgresql postgresql-contrib

安装 pgvector 扩展：
  sudo apt install -y postgresql-15-pgvector
  # 如果 apt 里没有，从源码编译：
  # git clone https://github.com/pgvector/pgvector.git
  # cd pgvector && make && sudo make install

安装 Python 依赖：
  pip install psycopg2-binary requests

3. 数据库配置
============================

3.1 创建数据库和用户：

  sudo -u postgres psql

  CREATE USER lmc5 WITH PASSWORD '你的密码';
  CREATE DATABASE lmc5 OWNER lmc5;
  \c lmc5
  CREATE EXTENSION vector;
  \q

3.2 测试连接：

  psql -U lmc5 -d lmc5 -h localhost
  # 输入密码，能进去就 OK


============================
4. API 密钥获取
============================

LMC-5 需要两个 API：

【A. Gemini API（用于 embedding 向量化）】

这是最容易卡住的一步。Google 的 Gemini API 有免费层和付费层：

  免费层限制：
  - gemini-embedding-2：每分钟 5 次请求，每天 500 次
  - 对于日常使用基本够用，但初始化导入大量记忆时会撞限额

  付费层（Pay-as-you-go）：
  - 需要绑信用卡
  - embedding 调用非常便宜（约 $0.00001/请求）
  - 限额大幅放开

获取步骤：
  1. 打开 https://aistudio.google.com/
  2. 用 Google 账号登录
  3. 左侧菜单 → "Get API key" → "Create API key"
  4. 选一个 Google Cloud 项目（没有就创建一个）
  5. 复制生成的 API key

升级到付费层（解决"配额层级"报错）：
  1. 打开 https://console.cloud.google.com/billing
  2. 创建或关联一个 Billing Account（需要信用卡）
  3. 把你的 Google Cloud 项目关联到这个 Billing Account
  4. 回到 AI Studio，确认项目已经关联 billing
  5. 在 https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com
     确认 "Generative Language API" 已启用

  关键：如果你在 AI Studio 生成 key 时看到"免费层"或
  "Free of charge"字样，说明还没升级。必须在 Google Cloud Console
  里把项目绑定到有信用卡的 billing account 才算付费层。

  常见报错：
  - "RESOURCE_EXHAUSTED" → 免费层额度用完，等一天或升级付费层
  - "PERMISSION_DENIED" → API 没启用，去 Cloud Console 启用
  - "Quota exceeded" → 同上，升级付费层


【B. DeepSeek API（用于后台 LLM 任务：做梦、评分等）】

  1. 打开 https://platform.deepseek.com/
  2. 注册账号
  3. 充值（最低 10 元人民币）
  4. API Keys → 创建密钥 → 复制

  DeepSeek 便宜且 JSON mode 稳定，推荐用这个。
  也可以换成 OpenAI 或其他兼容 API。


============================
5. 环境变量配置
============================

  cd lmc-5/extras/pgvector_backend
  cp .env.example .env
  vim .env  # 或用你喜欢的编辑器

必填项：

  # 数据库连接
  LMC5_PG_DSN=postgresql://lmc5:你的密码@localhost:5432/lmc5

  # Gemini embedding
  GEMINI_API_KEY=你的gemini-api-key
  LMC5_EMBED_MODEL=gemini-embedding-2
  LMC5_EMBED_DIM=3072

  # DeepSeek（后台 LLM）
  DEEPSEEK_API_KEY=你的deepseek-api-key

  # 时区
  TZ=Asia/Shanghai

可选项（有默认值，一般不用改）：

  # 去重阈值（0.92 是默认，越高越严格）
  # LMC5_DEDUP_SIMILARITY=0.92

  # 做梦时 importance 门槛（默认 7，记忆少可以降到 5）
  # LMC5_DREAM_IMPORTANCE_THRESHOLD=7


============================
6. 初始化数据库表
============================

  psql -U lmc5 -d lmc5 -h localhost -f schema.sql

检查是否成功：
  psql -U lmc5 -d lmc5 -h localhost -c "\dt lmc5_*"

应该看到这些表：
  - lmc5_curated_memories（主记忆表）
  - lmc5_vectors（向量表）
  - lmc5_memory_relations（记忆关系/Y轴）
  - lmc5_z_audit（事实审计/Z轴）
  - lmc5_cold_storage（冷归档）
  - lmc5_narrative_index（叙事时间线/X轴）
  - lmc5_e_axis_failures（情感评分失败日志）
  - lmc5_dynamic_stopwords（停用词）
  - lmc5_raw_events（原始事件日志）


============================
7. 验证安装
============================

测试 embedding 是否能用：

  python3 -c "
  import os
  os.environ['GEMINI_API_KEY'] = '你的key'
  from extras.pgvector_backend.embedders import gemini_embedder
  emb = gemini_embedder()
  if emb:
      vec = emb('测试文本')
      if vec:
          print(f'OK! 向量维度: {len(vec)}')
      else:
          print('ERROR: embedding 调用失败')
  else:
      print('ERROR: API key 无效或缺失')
  "

期望输出：OK! 向量维度: 3072

测试数据库连接：

  python3 -c "
  import psycopg2
  conn = psycopg2.connect('postgresql://lmc5:你的密码@localhost:5432/lmc5')
  cur = conn.cursor()
  cur.execute('SELECT count(*) FROM lmc5_curated_memories')
  print(f'OK! 当前记忆数: {cur.fetchone()[0]}')
  conn.close()
  "


============================
8. 常见问题排查
============================

Q: 报错 "配额层级" / "RESOURCE_EXHAUSTED"
A: Gemini API 还在免费层。去 Google Cloud Console 绑信用卡升级到
   Pay-as-you-go 层级。见第 4 节。

Q: embedding 维度不对 / halfvec 报错
A: schema.sql 默认是 3072 维（gemini-embedding-2）。如果用 Voyage
   或 BGE-M3（1024维），需要同步改 schema.sql 里的 halfvec(3072)
   为 halfvec(1024)，并重建索引。

Q: DeepSeek 调用超时
A: 检查服务器是否能访问 api.deepseek.com。境内服务器一般没问题，
   境外可能需要代理。也可以换成 OpenAI 等其他 LLM。

Q: pgvector 扩展装不上
A: 确认 PostgreSQL 版本 >= 15，且安装了对应版本的 pgvector 包。
   Ubuntu: apt install postgresql-15-pgvector
   如果包管理器没有，从源码编译：
   git clone https://github.com/pgvector/pgvector.git
   cd pgvector && make && sudo make install
   然后在数据库里 CREATE EXTENSION vector;

Q: 如何接入 Claude Code / MCP
A: extras/pgvector_backend/hooks/ 目录下有三个 Claude Code hook：
   - session_start.py（启动时加载身份和最近记忆）
   - user_prompt_submit.py（每轮对话自动召回相关记忆）
   - session_end.py（会话结束归档原始事件）
   具体接线方式看 hooks 目录里的 docstring。

Q: 如何跑夜间做梦（自动整理记忆）
A: python -m extras.pgvector_backend.dream_runner
   推荐用 cron 或 systemd timer 每天凌晨 4 点跑一次。
   加 --dry-run 可以预览不写入。


============================
架构简述（给想深入的人看）
============================

LMC-5 的记忆分五个轴（XYZEM）：
- X 轴（叙事时间线）：周/月维度的叙事摘要
- Y 轴（关系图谱）：记忆之间的关联（因果、同主题、时序等）
- Z 轴（事实演化）：同一事实的多版本管理，旧的自动标记 superseded
- E 轴（情感信号）：valence/arousal/tension 三维情感标注
- M 轴（代谢排序）：权重衰减 + 命中加权 + 时间涟漪

三层检索优先级：
  1. 向量语义检索（主路径）
  2. curated 全文检索（语义不够时的后备）
  3. 原始事件全文检索（最后兜底）

侧通道：Y轴图扩展、E轴情感共鸣、自发回忆。

记忆流向：
  原始对话 → raw_events → hippocampus（做梦）→ curated_memories
  永远不跳过 hippocampus 直接写 curated。

附：完整 .env 模板

# 数据库
LMC5_PG_DSN=postgresql://lmc5:PASSWORD@localhost:5432/lmc5
LMC5_PG_POOL_SIZE=5

# Embedding（三选一，推荐 Gemini）
GEMINI_API_KEY=
LMC5_EMBED_MODEL=gemini-embedding-2
LMC5_EMBED_DIM=3072

# 后台 LLM（推荐 DeepSeek）
DEEPSEEK_API_KEY=
LMC5_HOUSEKEEPER_MODEL_CHEAP=deepseek-chat
LMC5_HOUSEKEEPER_MODEL_HEAVY=deepseek-v4-pro

# 时区
TZ=Asia/Shanghai

# 日志和备份
LMC5_LOG_DIR=/var/log/lmc5
LMC5_BACKUP_DIR=/var/backups/lmc5
