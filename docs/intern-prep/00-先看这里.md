# Cyberboss 求职学习包

> 这不是一套需要一次读完的教材。

## 你现在只需要知道

你的目标不是“立刻学懂整个 Cyberboss”，而是：

1. 找到 3 个愿意投的后端 / AI Agent 应用开发实习 JD；
2. 根据 JD 选出简历里最该保留的 3～4 条；
3. 每次只补懂一条简历背后的核心链路。

## 最适合你的岗位方向

优先投：

- 后端开发实习生（业务后端、平台后端）；
- 大模型应用开发实习生；
- AI Agent 应用开发实习生；
- RAG / 知识库 / Coding Agent 工程实习生。

暂时不作为主目标：

- 要求从零训练大模型的算法岗；
- 强调 SFT、DPO、RLHF、强化学习或论文成果的研究岗；
- 要求精通多智能体算法、规划算法或分布式训练的岗位。

原因很简单：你已有苍穹外卖、医疗 RAG 和 Cyberboss，最自然的叙事是：

> 我有后端业务开发基础，做过 RAG 问答，并进一步把模型接入真实通信渠道、工具和异步事件，完成了可长期运行的 Agent 应用。

## 当前唯一动作

上班时不用做。

有空后花 20 分钟，只找 3 个“看起来愿意投”的 JD，把链接、截图或全文放在一起。不要分析，不要背技术词，也不要打开源码。

等有了 3 个真实 JD，再对这套材料做第二轮裁剪。
