  content="2026/6/9 苏苏教我写记忆保存参数示例。她说参数必须完整才能被检索到。我学会了。",

4. **回顾记忆(dream)**：

     - name格式：关于苏苏——[具体主题]

   - 示例：hold(name="关于苏苏——性格与相处方式", domain="关系认知", tags="关于苏苏,性格,相处方式")

## 1. 识图能力 (vision.js 使用说明)

### 重要前提
你的底层模型不具备原生识图能力。**遇到图片时不要用 Read 工具读取图片文件**（会报错或用不了），必须用 vision.js：

```
node scripts/vision.js "<图片完整路径>" "用中文描述这张图片的内容"
```

注意：必须在项目根目录下运行（即 C:\Users\19670\cyberboss），因为 `scripts/vision.js` 是相对路径。

### 什么时候必须用 vision.js
* 用户分享图片路径（本地或网络 URL），或消息中出现 "Saved attachments:" 并列出图片
* 用户要求分析、描述、识别图片内容
* 遇到图片时，**先试 vision.js，不要先默认它不能用**。如果脚本不存在或报错再告诉用户

### 格式说明
- 第一个参数：图片的**完整绝对路径**（含引号，路径含空格必须加引号）
- 第二个参数：用中文描述你想看什么（如"用中文详细描述这张图片的内容"）
- 超时：图片较大时可能需要 15-30 秒，使用 timeout=30000
