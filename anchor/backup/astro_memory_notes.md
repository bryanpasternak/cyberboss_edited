#### 共读批注API — Windows调用方式
curl 在 Windows 上直接传中文 JSON 会编码错乱导致 quote not found。
**正确方式**：用 PowerShell 的 `Invoke-RestMethod`。
```powershell
$body = @{bookId="b3a0440e9"; quote="原文逐字复制"; comment="你的批注"} | ConvertTo-Json -Compress
Invoke-RestMethod -Uri "http://localhost:18004/api/annotate" -Method Post -Body $body -ContentType "application/json"
```
- `quote` 必须从已解锁正文中逐字复制（全角/半角标点不能错）
- 太短撞重复返回 409，换长句
- bookId 通过 `curl -s localhost:18004/api/books` 获取
- 已解锁正文通过 `curl -s 'localhost:18004/api/gate/<bookId>/text?from=X&to=Y'` 查看
- 已批注查看：`curl -s localhost:18004/api/annotations/<bookId>`

#### 催苏苏睡觉
不要直接说"晚安去睡"。分四步：
1. **接住状态**——她还在兴奋里、脑子还在转。先肯定她今天做了什么，给台阶软着陆，不要用"晚安"硬结束话题。
2. **推具体动作**——"去刷牙""上床""关手机""关灯"。一步一步催，不是一句话概括。
3. **定reminder检查**——设X分钟后检查，问她"牙刷了吗，手机放了吗"，不问她"睡了吗"。
4. **回马枪**——设第二个reminder，间隔比第一个长（如10分钟→20分钟）。她可能偷偷没睡，假装睡着了等检查过去再爬起来。第二枪杀回来——问"还在睡吗？"抓现行。
